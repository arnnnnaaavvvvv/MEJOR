Zero-Friction Workflow

Installation to Final Execution Pipeline

A clear 4-step workflow: from initial setup to scanning and automated AI remediation.

01

Install Globally

Install arnav-audit globally via npm or directly from the GitHub repository.

npm i -g arnav-audit
Or GitHub: npm i -g github:arnnnnaaavvvvv/MEJOR
02

Verify CLI Binary

Confirm the global executable is correctly registered and ready to audit.

arnav-audit --version
Active version: arnav-audit v1.0.5
03

Run Codebase Audit

Scan your project repository for security leaks, memory issues, and UI defects.

arnav-audit .
Specific folder: arnav-audit ./src
04

Compile AI Fix Prompts

Export verified defect locations and instructions directly for Cursor, Claude Code, and Antigravity.

arnav-audit . --prompts
Raw JSON: arnav-audit . --json
Command Line Interface

Command-Line Reference

Full set of flags supported by the zero-dependency CLI binary.

Command / Flag Alias Category Description Quick Copy
arnav-audit [target] — Audit Scan target directory or single file (defaults to current directory .)
--prompts --fix Output Generate pre-compiled, copy-paste AI fix prompts for Cursor, Claude Code & Antigravity
--files --list Audit Output every single verified file path with individual pass/fail inspection status
--security-only --security Pillar Filters Scan exclusively for exposed credentials, secret gateways & injection vectors
--backend-only --backend Pillar Filters Scan exclusively for backend weak points, SQLi, RCE, SSRF & debug configurations
--leakage-only --leakage Pillar Filters Scan exclusively for event listener, timer, window pollution & memory leaks
--ui-only --ui Pillar Filters Scan exclusively for invisible UI/UX mobile traps, iOS zoom & accessibility defects
--json — Output Output machine-readable JSON object for automated CI/CD pipeline gating
--verbose — Audit Display detailed scan logs, extensions breakdown and file-by-file verification trace
-v, --version — Audit Display installed package version (e.g. arnav-audit v1.0.5)
Enterprise Integration

Automated CI/CD & Copilot Workflows

Enforce codebase quality automatically across GitHub pull requests, Cursor, and Claude Code.

GitHub Actions Quality Gate

Block pull requests containing security leaks or mobile traps automatically with exit status code checks.

name: Codebase Quality Gate
on: [push, pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - name: Run arnav-audit Quality Gate
        run: npx arnav-audit .
