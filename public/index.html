Command-Line Reference

Full set of flags supported by the zero-dependency CLI binary.

Command / Flag Alias Description
arnav-audit [directory] — Audit specified directory (defaults to current directory .)
--prompts --fix Generate pre-compiled, copy-paste AI fix prompts for Cursor & Claude Code
--files --list Output every single verified file path with individual pass/fail status
--security-only --security Scan exclusively for exposed credentials, secrets & injection vectors
--leakage-only --leakage Scan exclusively for event listener, timer & window memory leaks
--json — Output machine-readable JSON for automated CI/CD gating
--verbose — Display detailed scan logs and file-by-file verification trace
-v, --version — Display installed package version

GitHub Actions CI Integration

Block pull requests containing security leaks or mobile traps automatically.

name: Codebase Quality Gate
on: [push, pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - name: Run arnav-audit
        run: npx arnav-audit .
